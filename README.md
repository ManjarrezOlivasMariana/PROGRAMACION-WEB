# Programación Web

Este repositorio contiene una colección de programas y ejercicios desarrollados durante mi aprendizaje de **Programación Web**. Aquí se incluyen prácticas relacionadas con el desarrollo front-end y/o back-end, utilizando tecnologías como HTML, CSS, JavaScript.

## 📌 Contenido

- Ejercicios prácticos de programación web
- Ejemplos de estructuras HTML
- Estilos con CSS
- Scripts en JavaScript

## 🎯 Objetivo

El propósito de este repositorio es documentar mi progreso y práctica en el desarrollo de aplicaciones web, aplicando los conocimientos adquiridos en la materia de Programación Web.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
